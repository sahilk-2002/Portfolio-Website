# Sahil Kulkarni — DevOps Portfolio

Multi-page static portfolio website built with pure HTML/CSS/JS. Dark terminal-themed design showcasing DevOps skills, projects, certifications, and experience.

## Pages

- **Home** — Terminal hero with typing animation
- **About** — Professional summary and quick info
- **Projects** — DevOps project cards with tech tags
- **Skills** — Categorized skill badges
- **Certifications** — Industry certification cards
- **Education** — Academic background
- **Contact** — Contact form and social links

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- GitHub Pages (hosting)
- GitHub Actions (CI/CD)

## Deployment

Push to `main` branch — GitHub Actions automatically deploys to GitHub Pages.
